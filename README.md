# Job Applicator

This repository holds released versions of Job Applicator. It contains no source history and no personal data:
each release is a zip with the app and a blank profile.

- **Install:** download the latest zip from [Releases](../../releases/latest), unzip it, and follow `README.md`
  inside (Windows: double-click `install.cmd`; Mac: right-click `install.command` and choose Open).
- **Updates:** installed copies check this repository about once a day and install new versions on their own.
- **Suggestions and problems:** use **Suggest an improvement** in the app, or open an [issue](../../issues).
